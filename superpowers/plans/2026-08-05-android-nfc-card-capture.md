# Android NFC Card Capture Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Let the app capture a refund card over Android's own NFC radio on devices whose Sunmi PaySDK reports no card hardware, without changing the Sunmi P2 path.

**Architecture:** A vendor-neutral `NfcTransport` (Android `NfcAdapter` reader mode + `IsoDep`) lives in the module's always-compiled `src/main` and emits the existing `onCardRead`/`onError` events. The Sunmi backend keeps trying PaySDK first and falls back to the transport only when `checkCard` answers `-20000`/`-20003` — the reader stating it cannot do NFC. Everything above the transport, including `readEmvCard`, is unchanged.

**Tech Stack:** Kotlin / Expo Modules API, Android `android.nfc` (`NfcAdapter`, `IsoDep`), TypeScript, Jest + `@testing-library/react-native`.

## Global Constraints

- **Spec:** `docs/superpowers/specs/2026-08-05-android-nfc-card-capture-design.md`. Read it before starting. It builds on `docs/superpowers/specs/2026-08-04-card-capture-device-capabilities-design.md`.
- **Working directory:** `c:\unirefund\pos-app`, branch `main`. All paths are relative to it.
- **Unknown means available.** Any signal that cannot be read leaves a method offered. A detection bug must never disable a working reader.
- **Only `-20000` and `-20003` demote a method.** `-30005` (timeout) and the rest of the `-3000x` family describe bad reads. Never hardcode these — use `UNSUPPORTED_ERROR_CODES` from `src/store/cardCapabilities.ts` in TS, and the existing `ERR_NOT_SUPPORTED`/`ERR_PARAMS` companion constants in Kotlin.
- **PaySDK wins where it works.** The Android transport serves `nfc` only where PaySDK cannot. The P2 must never reach it.
- **NFC switched off is not "unsupported".** It gets a prompt, not a demotion.
- Card modes and display order: `nfc`, `magnetic`, `ic`.
- `t()` takes no interpolation parameters — every string is a complete sentence.
- Never edit `src/data/language-data/*.gen.json` by hand; they are gitignored build artifacts regenerated by `npm run init`.
- **Baseline to hold:** 21 suites / 237 tests passing, typecheck clean, lint **35 warnings / 0 errors**.
- Existing UI primitives only; no new libraries; no hardcoded user-visible text.
- Run `npm test`, `npm run typecheck` and `npm run lint` before every commit.
- **No device is available.** The Sunmi P2 and V3 are both unreachable. Verify Kotlin with `cd android && ./gradlew :app:assembleDebug` in the **foreground** — never end a turn while a build runs. Do not attempt `adb` or `expo run:android`.

### Repo gotchas that have already bitten implementers

1. `jest.mock()` factories cannot close over outer variables (`babel-plugin-jest-hoist`) — declare inside the factory, pull out with `jest.requireMock`. Precedents: `src/hooks/__tests__/useCardCapabilities.test.tsx`, `src/actions/auth/__tests__/actions.test.ts`.
2. The persisted zustand store's `set()` returns a promise; an expression-bodied `act(() => storeAction())` leaks it and corrupts React's shared act queue, breaking every *later* test in the file. Use block-bodied callbacks.
3. RNTL `fireEvent` walks up to composite props, so it cannot prove the absence of a handler.
4. A mocked hook returning a stable object does not re-render on mutation — drive a rerender explicitly.
5. Focused jest runs need the `(auth)` parentheses escaped; jest reads them as regex.

- [ ] **Step 1: Add the shared hex helpers**

Create `Hex.kt`:

```kotlin
package expo.modules.sunmicardreader

/**
 * Hex helpers shared by every transport in this module. They live at package
 * scope in src/main (not on a backend class) because both the Sunmi PaySDK
 * path and the vendor-neutral NFC path speak APDUs and must agree byte for
 * byte on the encoding.
 */

internal fun hexToBytes(hex: String): ByteArray {
  val clean = hex.filter { !it.isWhitespace() }
  val out = ByteArray(clean.length / 2)
  for (i in out.indices) {
    out[i] = ((Character.digit(clean[i * 2], 16) shl 4) +
      Character.digit(clean[i * 2 + 1], 16)).toByte()
  }
  return out
}

/**
 * @param len how many leading bytes of [bytes] are meaningful. The Sunmi SDK
 *   fills an oversized output buffer and returns the real length separately,
 *   so callers there must pass it; IsoDep returns an exactly-sized array and
 *   can rely on the default.
 */
internal fun bytesToHex(bytes: ByteArray, len: Int = bytes.size): String {
  val sb = StringBuilder(len * 2)
  for (i in 0 until len) sb.append(String.format("%02X", bytes[i].toInt() and 0xFF))
  return sb.toString()
}
```

Create `NfcTransport.kt`:

```kotlin
package expo.modules.sunmicardreader

import android.app.Activity
import android.content.Context
import android.nfc.NfcAdapter
import android.nfc.Tag
import android.nfc.tech.IsoDep
import android.os.Handler
import android.os.Looper
import android.util.Log
import expo.modules.kotlin.Promise

/** Outcome of trying to arm reader mode. Distinguishes "no radio" from "radio
 *  switched off", because only the second one is worth prompting the user about. */
enum class NfcStartResult { STARTED, NO_ADAPTER, DISABLED, NO_ACTIVITY }

/**
 * Card capture over Android's own NFC radio.
 *
 * Deliberately contains no Sunmi imports and lives in src/main, so it compiles
 * into every build variant — including the stub — and works on any Android
 * device with an NfcAdapter. It emits the same "onCardRead"/"onError" events as
 * the PaySDK path, so nothing above the transport can tell them apart.
 *
 * @param onSessionEnd invoked when a scan finishes WITHOUT leaving an APDU
 *   channel open (a non-IsoDep tag, a failed connect, or a timeout). It is NOT
 *   invoked after a successful connect, because the caller then owns a live
 *   channel until it cancels. The backend uses this to release its reader
 *   ownership token; without it a timed-out scan would hold the token forever.
 */
class NfcTransport(
  private val context: Context,
  private val activityProvider: () -> Activity?,
  private val emit: EventEmitter,
  private val onSessionEnd: () -> Unit,
) {
  private val mainHandler = Handler(Looper.getMainLooper())

  @Volatile private var isoDep: IsoDep? = null
  @Volatile private var scanning = false
  @Volatile private var timeoutRunnable: Runnable? = null

  private fun adapter(): NfcAdapter? =
    try {
      NfcAdapter.getDefaultAdapter(context)
    } catch (e: Throwable) {
      Log.w(TAG, "getDefaultAdapter threw", e)
      null
    }

  /** Whether this device has an NFC radio at all, enabled or not. */
  fun isPresent(): Boolean = adapter() != null

  /** Whether the radio exists and is switched on. */
  fun isEnabled(): Boolean = adapter()?.isEnabled == true

  fun startScan(timeoutSec: Int): NfcStartResult {
    val a = adapter() ?: return NfcStartResult.NO_ADAPTER
    if (!a.isEnabled) return NfcStartResult.DISABLED
    val activity = activityProvider() ?: return NfcStartResult.NO_ACTIVITY

    scanning = true
    // enableReaderMode binds to an Activity's lifecycle; do it on the main
    // thread even though the API tolerates others, so ordering against
    // disableReaderMode is deterministic.
    mainHandler.post {
      try {
        a.enableReaderMode(
          activity,
          { tag -> onTag(tag) },
          NfcAdapter.FLAG_READER_NFC_A or
            NfcAdapter.FLAG_READER_NFC_B or
            NfcAdapter.FLAG_READER_SKIP_NDEF_CHECK,
          null,
        )
        Log.i(TAG, "reader mode armed (timeout=${timeoutSec}s)")
      } catch (e: Throwable) {
        Log.e(TAG, "enableReaderMode threw", e)
        emit("onError", mapOf("code" to ERR_READ_CARD_FAIL, "message" to (e.message ?: "enableReaderMode failed")))
        stopSession()
      }
    }

    val runnable = Runnable {
      if (!scanning) return@Runnable
      Log.i(TAG, "reader mode timed out")
      emit("onError", mapOf("code" to ERR_READ_CARD_TIMEOUT, "message" to "Timeout"))
      stopSession()
    }
    timeoutRunnable = runnable
    mainHandler.postDelayed(runnable, timeoutSec * 1000L)
    return NfcStartResult.STARTED
  }

  /** Reader-mode callback. Runs on an NFC service thread, so blocking IO here
   *  is correct — it must never be moved to the main thread. */
  private fun onTag(tag: Tag) {
    if (!scanning) return
    cancelTimeout()
    val uid = bytesToHex(tag.id)

    val iso = IsoDep.get(tag)
    if (iso == null) {
      // Mifare, transit, NDEF-only: no APDU channel, so no EMV read is
      // possible. Report the UID with no cardType so the JS layer settles
      // without attempting one and shows "card number could not be read".
      Log.i(TAG, "tag is not IsoDep; reporting UID only")
      emit("onCardRead", mapOf("mode" to "nfc", "uuid" to uid))
      stopSession()
      return
    }

    try {
      iso.connect()
      iso.timeout = ISO_DEP_TIMEOUT_MS
      isoDep = iso
      // Session intentionally stays open: the JS EMV reader now drives
      // transmitApdu against this channel until the caller cancels.
      emit("onCardRead", mapOf("mode" to "nfc", "uuid" to uid, "cardType" to NFC_CARD_TYPE))
    } catch (e: Throwable) {
      Log.e(TAG, "IsoDep connect failed", e)
      emit("onError", mapOf("code" to ERR_READ_CARD_FAIL, "message" to (e.message ?: "IsoDep connect failed")))
      stopSession()
    }
  }

  fun transmitApdu(apduHex: String, promise: Promise) {
    val iso = isoDep
    if (iso == null || !iso.isConnected) {
      promise.reject("NO_TAG", "No NFC tag connected", null)
      return
    }
    try {
      promise.resolve(bytesToHex(iso.transceive(hexToBytes(apduHex))))
    } catch (e: Throwable) {
      Log.e(TAG, "transceive failed", e)
      promise.reject("APDU_EX", e.message ?: "transceive failed", e)
    }
  }

  fun cancelScan() = stopSession()

  private fun cancelTimeout() {
    timeoutRunnable?.let { mainHandler.removeCallbacks(it) }
    timeoutRunnable = null
  }

  /** Idempotent teardown. Safe to call from any thread and more than once. */
  private fun stopSession() {
    val wasScanning = scanning
    scanning = false
    cancelTimeout()
    try { isoDep?.close() } catch (_: Throwable) {}
    isoDep = null
    val a = adapter()
    val activity = activityProvider()
    if (a != null && activity != null) {
      mainHandler.post {
        try { a.disableReaderMode(activity) } catch (e: Throwable) { Log.w(TAG, "disableReaderMode threw", e) }
      }
    }
    if (wasScanning) onSessionEnd()
  }

  companion object {
    private const val TAG = "NfcTransport"
    /** How long a single APDU exchange may take. */
    private const val ISO_DEP_TIMEOUT_MS = 5_000
    /**
     * Sunmi's AidlConstants.CardType.NFC value, carried purely so the JS layer
     * has an opaque handle to pass back into transmitApdu. The value is ignored
     * on this path — the backend dispatches on its ownership token, not on this.
     */
    private const val NFC_CARD_TYPE = 4
    /** AidlErrorCode.READ_CARD_FAIL */
    private const val ERR_READ_CARD_FAIL = -30001
    /** AidlErrorCode.READ_CARD_TIMEOUT — deliberately NOT a demoting code. */
    private const val ERR_READ_CARD_TIMEOUT = -30005
  }
}
```

package expo.modules.sunmicardreader

import android.app.Activity
import android.content.Context
import android.util.Log
import expo.modules.kotlin.Promise

/**
 * STUB backend — compiled when the Sunmi Pay SDK is deliberately excluded
 * (`-PsunmiCardReaderStub=true`; see build.gradle).
 *
 * It has no PaySDK, but Android's NFC radio is not Sunmi-specific, so this
 * variant still serves `nfc` through [NfcTransport]. That is the point of
 * keeping the transport in src/main: a stub build on ordinary Android hardware
 * can still capture a card.
 */
class SunmiCardReaderBackend(
  context: Context,
  activityProvider: () -> Activity?,
  private val emit: EventEmitter,
) : CardReaderBackend {

  private var nfcSessionOpen = false

  private val nfc = NfcTransport(context, activityProvider, emit) { nfcSessionOpen = false }

  override fun isSupported(): Boolean = nfc.isPresent()

  override fun initialize(promise: Promise) {
    Log.i(TAG, "Stub build: no Sunmi Pay SDK. NFC present=${nfc.isPresent()}.")
    promise.resolve(nfc.isPresent())
  }

  override fun startScan(modes: List<String>, timeoutSec: Int) {
    if (modes.size != 1 || modes[0] != "nfc") {
      emit("onError", mapOf("code" to ERR_NOT_SUPPORTED, "message" to "Only NFC is available in a stub build"))
      return
    }
    when (nfc.startScan(timeoutSec)) {
      NfcStartResult.STARTED -> nfcSessionOpen = true
      NfcStartResult.DISABLED ->
        emit("onError", mapOf("code" to ERR_NFC_DISABLED, "message" to "NFC is disabled"))
      else ->
        emit("onError", mapOf("code" to ERR_NOT_SUPPORTED, "message" to "No NFC adapter"))
    }
  }

  override fun transmitApdu(cardType: Int, apduHex: String, promise: Promise) {
    nfc.transmitApdu(apduHex, promise)
  }

  override fun cancelScan() {
    nfc.cancelScan()
  }

  override fun getDiagnostics(promise: Promise) {
    promise.resolve(
      mapOf(
        "buildModel" to android.os.Build.MODEL,
        "androidNfcPresent" to nfc.isPresent(),
        "androidNfcEnabled" to nfc.isEnabled(),
        "errors" to mapOf("backend" to "stub build: Sunmi Pay SDK not bundled"),
      ),
    )
  }

  override fun probeModes(modes: List<String>, promise: Promise) {
    // Omit magnetic and ic rather than claiming a verdict: this build never
    // touched that hardware, so it has disproven nothing (Decision 5).
    val results = HashMap<String, Any?>()
    if (modes.contains("nfc") && nfc.isPresent()) {
      results["nfc"] = mapOf("supported" to true, "message" to "Android NFC transport")
    }
    promise.resolve(results)
  }

  override fun destroy() {
    nfc.cancelScan()
  }

  companion object {
    private const val TAG = "SunmiCardReader"
    /** AidlErrorCode.INVOKING_NOT_SUPPORT */
    private const val ERR_NOT_SUPPORTED = -20000
    /** Module-local: NFC radio present but switched off. */
    private const val ERR_NFC_DISABLED = -4
  }
}

- [ ] **Step 4: Add the fallback helper**

Add these private methods to the class:

```kotlin
  /**
   * Hands an NFC scan to the Android transport.
   *
   * @return true when this call has been fully handled — either reader mode is
   *   armed, or an error explaining why it could not be has already been
   *   emitted. false means the caller should surface its own error instead.
   */
  private fun handleWithAndroidNfc(timeoutSec: Int): Boolean {
    val owner = ReaderOwner.NfcScan()
    if (!readerOwner.compareAndSet(null, owner)) {
      Log.w(TAG, "handleWithAndroidNfc: reader busy")
      return false
    }
    nfcOwner = owner
    return when (val result = nfc.startScan(timeoutSec)) {
      NfcStartResult.STARTED -> true
      NfcStartResult.DISABLED -> {
        // The radio exists and simply needs switching on. Emitting a distinct
        // code lets the UI prompt for that instead of reporting a dead reader —
        // marking it unsupported would disable a working one (Decision 4).
        releaseNfcOwner(owner)
        emit("onError", mapOf("code" to ERR_NFC_DISABLED, "message" to "NFC is disabled"))
        true
      }
      else -> {
        Log.i(TAG, "Android NFC unavailable ($result)")
        releaseNfcOwner(owner)
        false
      }
    }
  }

  private fun releaseNfcOwner(owner: ReaderOwner.NfcScan) {
    readerOwner.compareAndSet(owner, null)
    if (nfcOwner === owner) nfcOwner = null
  }

  /**
   * True when a PaySDK error means "this reader cannot do NFC at all", as
   * opposed to an ordinary bad read. Only those two codes justify switching
   * transports; a timeout means the reader works and nobody tapped.
   */
  private fun isPaySdkCannotServe(code: Int): Boolean =
    code == ERR_NOT_SUPPORTED || code == ERR_PARAMS
```

- [ ] **Step 5: Try PaySDK first, then fall back**

Replace `startScan`'s opening, up to and including the `checkCard` call:

```kotlin
  override fun startScan(modes: List<String>, timeoutSec: Int) {
    // Only a single-mode NFC scan can fall back: the sheet always arms exactly
    // one method, and a combined bitmask has no unambiguous NFC-only meaning.
    val nfcOnly = modes.size == 1 && modes[0] == "nfc"

    val rc = readCard
    if (rc == null) {
      // No PaySDK reader at all (non-Sunmi hardware, or the service never
      // bound). Android NFC is the only transport that could work here.
      if (nfcOnly && handleWithAndroidNfc(timeoutSec)) return
      emit("onError", mapOf("code" to -2, "message" to "Reader not connected"))
      return
    }
    var cardType = 0
    for (mode in modes) cardTypeFor(mode)?.let { cardType = cardType or it }
    if (cardType == 0) return

    // Shares readerOwner with probeModes so the two entry points cannot
    // interleave on the same ReadCardOptV2 handle. `owner` is this call's own
    // token: held until its scan callback fires (find*/onError*) or
    // cancelScan() releases it — never a different session's.
    val owner = ReaderOwner.Scan()
    if (!readerOwner.compareAndSet(null, owner)) {
      Log.w(TAG, "startScan: reader busy (capability probe in progress)")
      emit("onError", mapOf("code" to -3, "message" to "Reader busy, try again"))
      return
    }

    try {
      // Defensively clear any transaction the EMV kernel may still be holding.
      // We deliberately do NOT call initEmvProcess(): this module never runs an
      // SDK EMV transaction (src/utils/emv.ts drives the chip over transmitApdu
      // itself), so initialising the kernel only creates unused state whose
      // terminal parameters are never configured. abortTransactProcess() is
      // void (verified via javap against PayLib-release 2.0.42), so there is no
      // return code to log; exceptions are logged rather than swallowed so
      // device differences are visible.
      try {
        emv?.abortTransactProcess()
      } catch (e: Throwable) {
        Log.w(TAG, "abortTransactProcess threw", e)
      }
      Log.i(TAG, "checkCard(cardType=$cardType, timeout=$timeoutSec)")
      rc.checkCard(cardType, newScanCallback(owner, nfcOnly, timeoutSec), timeoutSec)
    } catch (e: Throwable) {
      readerOwner.compareAndSet(owner, null)
      Log.e(TAG, "checkCard failed", e)
      // checkCard could not even be issued. If this was an NFC scan, the
      // Android transport is still worth trying before giving up.
      if (nfcOnly && handleWithAndroidNfc(timeoutSec)) return
      emit("onError", mapOf("code" to -1, "message" to (e.message ?: "checkCard failed")))
    }
  }
```

## Notes for the implementer

- **The P2 must not change behaviour.** Every fallback path is gated on a PaySDK error code that a working reader never returns. If you find yourself adding a condition that could fire on a healthy P2, stop and reconsider.
- **`-30005` must never trigger a fallback.** A timeout means the reader armed fine and nobody tapped. Only `-20000`/`-20003` mean "this reader cannot".
- **Reader mode is tied to activity foreground.** Android disables it on pause and does not restore it on resume. The sheet's existing cancel-on-unmount plus re-arm-on-ready covers the normal path; do not add lifecycle handling speculatively.
- **There is no JVM test harness** under `modules/sunmi-card-reader/android`. The Kotlin is verified by compilation and code tracing only. Say so plainly in your report rather than implying more.
