# Unused Localization Key Removal Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Delete localization keys that no code path can reach from `web-app/apps/web` and `web-app/apps/ssr`, and leave behind a committed detector so the dead weight does not silently regrow.

**Architecture:** A single Node script at `web-app/scripts/find-unused-i18n.mjs` scans app and package sources, then applies five guard layers (literal substring, template-literal prefix, schema-form-derived prefix, dot-terminated prefix constant, explicit allowlist). Keys matching no layer are dead. Pruning is line-based, not JSON re-serialisation, so key order, escaping and CRLF endings survive and the diff is deletions only — with one unavoidable exception: when a file's *final* entry is deleted, its predecessor loses a trailing comma, which git reports as one changed line. Before pruning, one real bug found during design is fixed: the Novu notification inbox is handed the wrong resource object.

**Tech Stack:** Node 20+ ESM (`.mjs`, no new dependencies), pnpm workspaces, Turborepo, TypeScript 6, Next.js 16.

## Global Constraints

- Working tree: `c:\unirefund\web-app`, branch `saas-update`, clean at plan time. Both prunes land as separate commits on this branch.
- `packages/utils` is a git submodule. Nothing in this plan may modify it.
- Never run `git reset --hard` in `web-app` — the checkout may be shared with another session.
- Never edit `apps/*/src/language-data/i18n/*.gen.json`. They are generated by `init.ts` and gitignored.
- Resource JSON files use **CRLF** line endings, 2-space indent, one entry per line, trailing newline. All 38 resource files across both apps were verified to hold exactly one entry per line and use CRLF. Any edit must preserve this.
- `pnpm run init` must run **before** `type-check`, or `tsc` reads a stale generated dictionary and a deletion goes unchecked.
- `init` needs `GATEWAY_URL` from `apps/<app>/.env` (`https://dev-api.unirefund.com`, confirmed reachable). Its outputs (`i18n/*.gen.json`, `packages/utils/policies/policies.json`) are both gitignored, so it produces no diff noise.
- Follow `web-app/.claude/rules/i18n.md`: never edit generated i18n files, never hardcode UI strings.
- Baselines confirmed green at plan time, both `tsc --noEmit` exit 0: `apps/web` and `apps/ssr`. Any type error during this work is therefore caused by this work.

- [ ] **Step 1: Create the detector script**

Create `web-app/scripts/find-unused-i18n.mjs` with exactly this content:

```js
#!/usr/bin/env node
/**
 * Reports (and optionally removes) localization keys in apps/<app>/src/language-data
 * that no code path can reach.
 *
 * Keys are not always referenced as literals - they are also built from template
 * literals, derived from JSON schemas by createUiSchemaWithResource, and looked up
 * with server-supplied names. Each guard layer below keeps the keys one of those
 * mechanisms can reach, so only keys matching no layer are reported as dead.
 *
 * Design: docs/superpowers/specs/2026-08-05-unused-i18n-keys-design.md
 *
 *   node scripts/find-unused-i18n.mjs --app=web
 *   node scripts/find-unused-i18n.mjs --app=ssr --prune
 */
import fs from "node:fs";
import path from "node:path";
import { fileURLToPath } from "node:url";

const SCRIPT_DIR = path.dirname(fileURLToPath(import.meta.url));
const SOURCE_EXTENSIONS = /\.(?:ts|tsx|js|jsx|mjs)$/;
const SKIP_DIRECTORIES = new Set(["node_modules", ".next", ".turbo", "dist"]);
const RESOURCE_SCOPES = ["core", "unirefund"];
const LOCALES = ["en", "tr"];

function parseArgs(argv) {
  const args = {
    app: "web",
    prune: false,
    root: path.resolve(SCRIPT_DIR, ".."),
  };
  for (const arg of argv) {
    if (arg === "--prune") args.prune = true;
    else if (arg === "--report") args.prune = false;
    else if (arg.startsWith("--app=")) args.app = arg.slice("--app=".length);
    else if (arg.startsWith("--root="))
      args.root = path.resolve(arg.slice("--root=".length));
    else throw new Error(`Unknown argument: ${arg}`);
  }
  if (!["web", "ssr"].includes(args.app)) {
    throw new Error(`--app must be "web" or "ssr", received "${args.app}"`);
  }
  return args;
}

function collectSourceFiles(dir, files = []) {
  if (!fs.existsSync(dir)) return files;
  for (const entry of fs.readdirSync(dir, { withFileTypes: true })) {
    if (SKIP_DIRECTORIES.has(entry.name)) continue;
    const full = path.join(dir, entry.name);
    if (entry.isDirectory()) collectSourceFiles(full, files);
    else if (SOURCE_EXTENSIONS.test(entry.name)) files.push(full);
  }
  return files;
}

/**
 * Builds the haystack every key is checked against: file contents plus the file
 * paths themselves, so a key named after a route segment survives.
 */
function buildCorpus(root, app) {
  const languageDataDir = `${path.sep}language-data${path.sep}`;
  const files = [
    ...collectSourceFiles(path.join(root, "apps", app, "src")).filter(
      (file) => !file.includes(languageDataDir)
    ),
    ...collectSourceFiles(path.join(root, "packages")),
  ];
  const contents = files.map((file) => fs.readFileSync(file, "utf8"));
  const paths = files.map((file) => file.split(path.sep).join("/"));
  return { corpus: [...contents, ...paths].join("\n \n"), fileCount: files.length };
}

/**
 * Prefixes whose whole key family must be kept, because the suffix is only known
 * at runtime.
 */
function collectPrefixes(corpus) {
  const prefixes = new Set();
  const add = (value) => {
    if (value && value.length >= 3 && !/[\s{}<>()]/.test(value)) {
      prefixes.add(value);
    }
  };

  // Layer 2 - template literals:  t.RefundService[`Batches.status.${status}`]
  for (const [, prefix] of corpus.matchAll(/`([^`$\n]*?)\$\{/g)) add(prefix);

  // Layer 3 - schema-form derives `${name}.${schemaProperty}` from generated SDK
  // schemas, so no per-field literal exists anywhere in the app.
  for (const [, name] of corpus.matchAll(
    /createUiSchemaWithResource[\s\S]{0,400}?name:\s*"([^"]+)"/g
  )) {
    add(`${name}.`);
  }
  if (corpus.includes("createUiSchemaWithResource")) add("Form.");

  // Layer 4 - dot-terminated constants:  SETTING_KEY_PREFIX = "CountryManagement."
  for (const [, prefix] of corpus.matchAll(
    /["']([A-Za-z][A-Za-z0-9_:]*(?:\.[A-Za-z0-9_:]+)*\.)["']/g
  )) {
    add(prefix);
  }

  return [...prefixes];
}

function loadAllowlist(root, app) {
  const file = path.join(root, "scripts", "i18n-allowlist.json");
  if (!fs.existsSync(file)) return [];
  const entries = JSON.parse(fs.readFileSync(file, "utf8"));
  return entries.filter((entry) => entry.app === app);
}

function isAllowlisted(allowlist, service, key) {
  return allowlist.some(
    (entry) =>
      entry.service === service &&
      (entry.pattern.endsWith("*")
        ? key.startsWith(entry.pattern.slice(0, -1))
        : key === entry.pattern)
  );
}

function collectResourceGroups(root, app) {
  const base = path.join(root, "apps", app, "src", "language-data");
  const groups = [];
  for (const scope of RESOURCE_SCOPES) {
    const dir = path.join(base, scope);
    if (!fs.existsSync(dir)) continue;
    for (const service of fs.readdirSync(dir)) {
      const resources = path.join(dir, service, "resources");
      if (fs.existsSync(path.join(resources, "en.json"))) {
        groups.push({ label: `${scope}/${service}`, service, resources });
      }
    }
  }
  return groups;
}

/** Keys from every locale, so tr-only orphans are judged by the same layers. */
function collectKeys(group) {
  const keys = new Set();
  for (const locale of LOCALES) {
    const file = path.join(group.resources, `${locale}.json`);
    if (!fs.existsSync(file)) continue;
    for (const key of Object.keys(JSON.parse(fs.readFileSync(file, "utf8")))) {
      keys.add(key);
    }
  }
  return [...keys];
}

function findDeadKeys(group, corpus, prefixes, allowlist) {
  return collectKeys(group).filter(
    (key) =>
      !corpus.includes(key) &&
      !prefixes.some((prefix) => key.startsWith(prefix)) &&
      !isAllowlisted(allowlist, group.service, key)
  );
}

/**
 * Deletes one line per dead key. Line-based rather than re-serialising, so key
 * order, escaping and CRLF endings survive and the diff is pure deletions.
 */
function pruneFile(file, deadKeys) {
  if (!fs.existsSync(file)) return 0;
  const original = fs.readFileSync(file, "utf8");
  const newline = original.includes("\r\n") ? "\r\n" : "\n";
  const lines = original.split(/\r?\n/);
  const dead = new Set(deadKeys);

  const kept = lines.filter((line) => {
    const match = /^\s*"((?:[^"\\]|\\.)*)":/.exec(line);
    return !(match && dead.has(JSON.parse(`"${match[1]}"`)));
  });
  const removed = lines.length - kept.length;
  if (removed === 0) return 0;

  // Removing the final entry would leave a trailing comma on its predecessor.
  for (let index = kept.length - 1; index >= 0; index -= 1) {
    const trimmed = kept[index].trim();
    if (!trimmed || trimmed === "}") continue;
    kept[index] = kept[index].replace(/,$/, "");
    break;
  }

  fs.writeFileSync(file, kept.join(newline));
  return removed;
}

function main() {
  const { app, prune, root } = parseArgs(process.argv.slice(2));
  const { corpus, fileCount } = buildCorpus(root, app);
  const prefixes = collectPrefixes(corpus);
  const allowlist = loadAllowlist(root, app);
  const groups = collectResourceGroups(root, app);

  console.log(
    `app=${app}  sources=${fileCount}  prefix guards=${prefixes.length}  allowlist entries=${allowlist.length}`
  );

  let deadTotal = 0;
  let removedTotal = 0;
  for (const group of groups) {
    const deadKeys = findDeadKeys(group, corpus, prefixes, allowlist);
    if (deadKeys.length === 0) continue;
    deadTotal += deadKeys.length;

    console.log(`\n${group.label}  (${deadKeys.length})`);
    for (const key of deadKeys) console.log(`  ${key}`);

    if (!prune) continue;
    for (const locale of LOCALES) {
      const file = path.join(group.resources, `${locale}.json`);
      const removed = pruneFile(file, deadKeys);
      removedTotal += removed;
      if (removed) console.log(`  -> removed ${removed} from ${locale}.json`);
    }
  }

  if (prune) {
    console.log(`\nremoved ${removedTotal} lines across ${LOCALES.length} locales`);
    return 0;
  }
  console.log(`\n${deadTotal} unreachable key(s)`);
  return deadTotal === 0 ? 0 : 1;
}

try {
  process.exit(main());
} catch (error) {
  console.error(`find-unused-i18n: ${error.message}`);
  process.exit(2);
}
```
