# Native Card Scan Tile Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a "Native scan" tile to the refund confirm sheet. It calls `CardScannerModule.startScan()`, which uses Google Pay card recognition on Android and VisionKit DataScanner on iOS, and fills the card fields. The existing Tap and Scan tiles stay unchanged.

**Architecture:** An Expo local module in `super-app/modules/card-scanner/` holds only the native code (Kotlin and Swift). Expo 54 autolinks it from `./modules`, so it survives `prebuild --clean`. A TypeScript wrapper in `src/utils/card/native-card-scanner.ts` looks the module up lazily, normalises its result, and gives every failure one of seven codes. `RefundPayoutStep.tsx` draws the card capture block once, not twice, and adds the tile, an error line and a placeholder warning to it.

**Tech Stack:** Expo SDK ~54.0.36, React Native 0.81.5 (New Architecture), Expo Modules API (expo-modules-core 3.0.30), `com.google.android.gms:play-services-wallet:19.5.0`, VisionKit/AVFoundation, Jest (jest-expo, `node` and `router` projects), NativeWind.

## Review Focus

1. **A scan that settles after the picker has unmounted** (dialog closed or method changed while the native screen was up) must apply nothing and call no `onChange`. Test: Task 4, "ignores a scan that lands after the picker is gone".
2. **A PAN that arrives with spaces or dashes** must reach the fields as digits only. Test: Task 1, "strips separators from the number".
3. **Expiry parts that are unset (`0`), out of range (`13`) or half-present** must yield no expiry, and a two-digit year must widen to `20YY`. Test: Task 1, "drops an expiry whose parts are unset, out of range or half-present" and "widens a two-digit year".
4. **A rejection that isn't one of ours** (an Expo `ERR_*`, a plain `Error`, a string) must read as `E_SCAN_FAILED` and show the generic message, never raw text. Tests: Task 1, "reads %s as E_SCAN_FAILED"; Task 4, the `it.each` row for a plain `Error`.
5. **The placeholder warning when another capture (OCR scan or NFC tap) replaces the card** must clear. Test: Task 4, "drops the warning when another capture replaces the card".

```ts
import { requireOptionalNativeModule } from "expo";
import { onlyDigits } from "./card";

/**
 * Google Pay's TEST or PRODUCTION environment (Android), or on-device
 * recognition (iOS). A "test" number is a placeholder, not the card scanned.
 */
export type NativeCardScanEnvironment = "test" | "production" | "device";

export type NativeCardScanResult = {
  pan: string;
  /** 1–12, present only together with `expiryYear`. */
  expiryMonth?: number;
  /** Four digits. */
  expiryYear?: number;
  environment: NativeCardScanEnvironment;
};

export type NativeCardScanErrorCode =
  | "E_CANCELLED"
  | "E_PERMISSION_DENIED"
  | "E_UNSUPPORTED"
  | "E_UNAVAILABLE"
  | "E_BUSY"
  | "E_SCAN_FAILED"
  | "E_MODULE_MISSING";

const ERROR_CODES: ReadonlySet<string> = new Set<NativeCardScanErrorCode>([
  "E_CANCELLED",
  "E_PERMISSION_DENIED",
  "E_UNSUPPORTED",
  "E_UNAVAILABLE",
  "E_BUSY",
  "E_SCAN_FAILED",
  "E_MODULE_MISSING",
]);

export class NativeCardScanError extends Error {
  readonly code: NativeCardScanErrorCode;

  constructor(code: NativeCardScanErrorCode, message: string) {
    super(message);
    this.name = "NativeCardScanError";
    this.code = code;
  }
}

type RawScanResult = {
  pan?: unknown;
  expiryMonth?: unknown;
  expiryYear?: unknown;
  environment?: unknown;
} | null;

type CardScannerNative = {
  startScan(): Promise<RawScanResult>;
  isSupportedAsync(): Promise<boolean>;
};

// Per call rather than at import: a dev client built before the module existed
// resolves it to null, and that must surface as a coded rejection, not a crash.
function nativeModule(): CardScannerNative | null {
  return requireOptionalNativeModule<CardScannerNative>("CardScanner");
}

export function nativeScanErrorCode(err: unknown): NativeCardScanErrorCode {
  const code = (err as { code?: unknown } | null | undefined)?.code;
  return typeof code === "string" && ERROR_CODES.has(code)
    ? (code as NativeCardScanErrorCode)
    : "E_SCAN_FAILED";
}

function monthOf(value: unknown): number | undefined {
  return typeof value === "number" &&
    Number.isInteger(value) &&
    value >= 1 &&
    value <= 12
    ? value
    : undefined;
}

function yearOf(value: unknown): number | undefined {
  if (typeof value !== "number" || !Number.isInteger(value) || value <= 0) {
    return undefined;
  }
  if (value < 100) return 2000 + value;
  return value >= 2000 && value <= 2099 ? value : undefined;
}

function environmentOf(value: unknown): NativeCardScanEnvironment {
  return value === "production" || value === "device" ? value : "test";
}

function normalize(raw: RawScanResult): NativeCardScanResult {
  const pan = typeof raw?.pan === "string" ? onlyDigits(raw.pan) : "";
  if (!pan) {
    throw new NativeCardScanError(
      "E_SCAN_FAILED",
      "The scan returned no card number.",
    );
  }
  const environment = environmentOf(raw?.environment);
  const expiryMonth = monthOf(raw?.expiryMonth);
  const expiryYear = yearOf(raw?.expiryYear);
  return expiryMonth && expiryYear
    ? { pan, expiryMonth, expiryYear, environment }
    : { pan, environment };
}

export const CardScannerModule = {
  /** Opens the platform's own card scanner. Rejects with `code` set to a `NativeCardScanErrorCode`. */
  async startScan(): Promise<NativeCardScanResult> {
    const native = nativeModule();
    if (!native) {
      throw new NativeCardScanError(
        "E_MODULE_MISSING",
        "This build does not include the CardScanner native module.",
      );
    }
    return normalize(await native.startScan());
  },

  /** Whether `startScan` can work on this device, without opening anything or asking for the camera. */
  async isSupportedAsync(): Promise<boolean> {
    const native = nativeModule();
    if (!native) return false;
    try {
      return (await native.isSupportedAsync()) === true;
    } catch {
      return false;
    }
  },
};
```

```kotlin
package expo.modules.cardscanner

import android.app.Activity
import android.content.IntentSender
import com.google.android.gms.wallet.PaymentCardRecognitionIntentRequest
import com.google.android.gms.wallet.PaymentCardRecognitionResult
import com.google.android.gms.wallet.PaymentsClient
import com.google.android.gms.wallet.Wallet
import com.google.android.gms.wallet.WalletConstants
import expo.modules.kotlin.Promise
import expo.modules.kotlin.events.OnActivityResultPayload
import expo.modules.kotlin.functions.Queues
import expo.modules.kotlin.modules.Module
import expo.modules.kotlin.modules.ModuleDefinition

// TEST returns a placeholder card instead of the one scanned. For real reads,
// switch to WalletConstants.ENVIRONMENT_PRODUCTION: that needs Google Pay
// production access for com.clomerce.unirefundsuperapp and its signing key,
// granted in the Google Pay & Wallet Console.
private const val WALLET_ENVIRONMENT = WalletConstants.ENVIRONMENT_TEST

// Below 0xFFFF: FragmentActivity rejects request codes that use the upper 16 bits.
private const val SCAN_REQUEST_CODE = 0x5CA7

class CardScannerModule : Module() {
  // Main thread only: both functions run there, as do Play Services task
  // listeners and activity results.
  private var pending: Promise? = null

  override fun definition() = ModuleDefinition {
    Name("CardScanner")

    AsyncFunction("isSupportedAsync") { promise: Promise ->
      val activity = appContext.currentActivity
      if (activity == null) {
        promise.resolve(false)
      } else {
        recognitionIntent(activity)
          .addOnSuccessListener { promise.resolve(true) }
          .addOnFailureListener { promise.resolve(false) }
      }
    }.runOnQueue(Queues.MAIN)

    AsyncFunction("startScan") { promise: Promise ->
      val activity = appContext.currentActivity
      when {
        pending != null ->
          promise.reject("E_BUSY", "A card scan is already running.", null)
        activity == null ->
          promise.reject("E_UNAVAILABLE", "There is no activity to open the scanner from.", null)
        else -> {
          pending = promise
          launch(activity)
        }
      }
    }.runOnQueue(Queues.MAIN)

    OnActivityResult { _, payload ->
      if (payload.requestCode == SCAN_REQUEST_CODE) {
        handleResult(payload)
      }
    }
  }

  private fun launch(activity: Activity) {
    recognitionIntent(activity)
      .addOnSuccessListener { response ->
        try {
          activity.startIntentSenderForResult(
            response.paymentCardRecognitionPendingIntent.intentSender,
            SCAN_REQUEST_CODE,
            null,
            0,
            0,
            0
          )
        } catch (e: IntentSender.SendIntentException) {
          settle { it.reject("E_SCAN_FAILED", "The card scanner could not be opened.", e) }
        }
      }
      .addOnFailureListener { e ->
        settle {
          it.reject("E_UNSUPPORTED", "Google Pay card recognition is not available on this device.", e)
        }
      }
  }

  private fun handleResult(payload: OnActivityResultPayload) {
    val data = payload.data
    if (payload.resultCode == Activity.RESULT_CANCELED) {
      settle { it.reject("E_CANCELLED", "The card scan was cancelled.", null) }
      return
    }
    if (payload.resultCode != Activity.RESULT_OK || data == null) {
      settle { it.reject("E_SCAN_FAILED", "The card scanner returned an error.", null) }
      return
    }
    val result = PaymentCardRecognitionResult.getFromIntent(data)
    val pan = result?.pan
    if (result == null || pan.isNullOrBlank()) {
      settle { it.reject("E_SCAN_FAILED", "The card scanner returned no card number.", null) }
      return
    }
    settle { it.resolve(toMap(pan, result)) }
  }

  private fun toMap(pan: String, result: PaymentCardRecognitionResult): Map<String, Any> {
    val environment =
      if (WALLET_ENVIRONMENT == WalletConstants.ENVIRONMENT_PRODUCTION) "production" else "test"
    val map = mutableMapOf<String, Any>("pan" to pan, "environment" to environment)
    result.creditCardExpirationDate?.let { date ->
      if (date.month in 1..12 && date.year > 0) {
        map["expiryMonth"] = date.month
        map["expiryYear"] = date.year
      }
    }
    return map
  }

  private fun settle(block: (Promise) -> Unit) {
    val promise = pending ?: return
    pending = null
    block(promise)
  }

  private fun recognitionIntent(activity: Activity) =
    paymentsClient(activity)
      .getPaymentCardRecognitionIntent(PaymentCardRecognitionIntentRequest.getDefaultInstance())

  private fun paymentsClient(activity: Activity): PaymentsClient =
    Wallet.getPaymentsClient(
      activity,
      Wallet.WalletOptions.Builder().setEnvironment(WALLET_ENVIRONMENT).build()
    )
}
```

```swift
import Foundation

/// Card number and expiry from scanned text lines, by the same rules as
/// src/utils/card/parse-card-ocr.ts. Digits are matched as [0-9] because
/// ICU's \d also matches non-ASCII digits.
enum CardTextParser {
  struct Card: Equatable {
    let pan: String
    let expiryMonth: Int?
    let expiryYear: Int?
  }

  private static let panPattern = try! NSRegularExpression(
    pattern: #"(?<![0-9])[0-9](?:[ -]?[0-9]){12,18}(?![0-9])"#)
  private static let expiryPattern = try! NSRegularExpression(
    pattern: #"(?<![0-9])([0-9]{2})\s*/\s*([0-9]{4}|[0-9]{2})(?![0-9])"#)
  private static let expiryLabel = try! NSRegularExpression(
    pattern: #"GOOD\s*THRU|EXPIRES?|VALID"#, options: .caseInsensitive)

  static func parse(_ rawLines: [String]) -> Card? {
    let lines = rawLines
      .flatMap { $0.components(separatedBy: .newlines) }
      .map { $0.trimmingCharacters(in: .whitespaces) }
      .filter { !$0.isEmpty }
    // Joined only when no single line holds a number, so a real PAN is never
    // fused with an unrelated line into a longer, coincidentally valid one.
    guard let pan = bestPan(in: lines) ?? bestPan(in: [lines.joined(separator: " ")]) else {
      return nil
    }
    let expiry = findExpiry(in: lines)
    return Card(pan: pan, expiryMonth: expiry?.month, expiryYear: expiry?.year)
  }

  static func luhnValid(_ digits: String) -> Bool {
    guard digits.count >= 12 else { return false }
    var sum = 0
    for (index, character) in digits.reversed().enumerated() {
      guard var value = character.wholeNumberValue else { return false }
      if index % 2 == 1 {
        value *= 2
        if value > 9 { value -= 9 }
      }
      sum += value
    }
    return sum % 10 == 0
  }

  private static func bestPan(in candidates: [String]) -> String? {
    var best: String?
    for candidate in candidates {
      let range = NSRange(candidate.startIndex..., in: candidate)
      for match in panPattern.matches(in: candidate, range: range) {
        guard let matched = Range(match.range, in: candidate) else { continue }
        let digits = String(candidate[matched].filter { $0 >= "0" && $0 <= "9" })
        guard luhnValid(digits) else { continue }
        if digits.count > (best?.count ?? 0) { best = digits }
      }
    }
    return best
  }

  private static func findExpiry(in lines: [String]) -> (month: Int, year: Int)? {
    for (index, line) in lines.enumerated() where hasExpiryLabel(line) {
      if let date = expiry(in: line) { return date }
      if index + 1 < lines.count, let date = expiry(in: lines[index + 1]) { return date }
    }
    for line in lines {
      if let date = expiry(in: line) { return date }
    }
    return nil
  }

  private static func hasExpiryLabel(_ line: String) -> Bool {
    let range = NSRange(line.startIndex..., in: line)
    return expiryLabel.firstMatch(in: line, range: range) != nil
  }

  private static func expiry(in line: String) -> (month: Int, year: Int)? {
    let range = NSRange(line.startIndex..., in: line)
    guard
      let match = expiryPattern.firstMatch(in: line, range: range),
      let monthRange = Range(match.range(at: 1), in: line),
      let yearRange = Range(match.range(at: 2), in: line),
      let month = Int(line[monthRange]), (1...12).contains(month),
      let year = Int(line[yearRange])
    else { return nil }
    return (month, year < 100 ? 2000 + year : year)
  }
}
```

```swift
import UIKit
import VisionKit

enum CardScanOutcome {
  case scanned(CardTextParser.Card)

  case failed(String)

/// DataScanner under a navigation bar with Cancel: the scanner draws no way
/// out of its own.
@available(iOS 16.0, *)
final class CardScanViewController: UIViewController, DataScannerViewControllerDelegate {
  /// How long a number with no expiry in view waits for one before it is returned alone.
  private static let expiryGraceNanoseconds: UInt64 = 1_500_000_000

  private let completion: @MainActor (CardScanOutcome) -> Void
  private let scanner: DataScannerViewController
  private var items: [RecognizedItem] = []
  private var numberOnly: CardTextParser.Card?
  private var grace: Task<Void, Never>?
  private var finished = false

  init(completion: @escaping @MainActor (CardScanOutcome) -> Void) {
    self.completion = completion
    self.scanner = DataScannerViewController(
      recognizedDataTypes: [.text()],
      qualityLevel: .accurate,
      recognizesMultipleItems: true,
      isHighFrameRateTrackingEnabled: false,
      isHighlightingEnabled: true
    )
    super.init(nibName: nil, bundle: nil)
  }

  required init?(coder: NSCoder) {
    fatalError("init(coder:) is not supported")
  }

  override func viewDidLoad() {
    super.viewDidLoad()
    navigationItem.leftBarButtonItem = UIBarButtonItem(
      barButtonSystemItem: .cancel, target: self, action: #selector(cancelTapped))
    addChild(scanner)
    scanner.view.frame = view.bounds
    scanner.view.autoresizingMask = [.flexibleWidth, .flexibleHeight]
    view.addSubview(scanner.view)
    scanner.didMove(toParent: self)
    scanner.delegate = self
  }

  override func viewDidAppear(_ animated: Bool) {
    super.viewDidAppear(animated)
    do {
      try scanner.startScanning()
    } catch {
      finish(.failed("The camera could not start scanning."))
    }
  }

  @objc private func cancelTapped() {
    finish(.cancelled)
  }

  func dataScanner(
    _ dataScanner: DataScannerViewController, didAdd addedItems: [RecognizedItem],
    allItems: [RecognizedItem]
  ) {
    consider(allItems)
  }

  func dataScanner(
    _ dataScanner: DataScannerViewController, didUpdate updatedItems: [RecognizedItem],
    allItems: [RecognizedItem]
  ) {
    consider(allItems)
  }

  func dataScanner(
    _ dataScanner: DataScannerViewController, didRemove removedItems: [RecognizedItem],
    allItems: [RecognizedItem]
  ) {
    items = allItems
  }

  func dataScanner(_ dataScanner: DataScannerViewController, didTapOn item: RecognizedItem) {
    guard let card = CardTextParser.parse(Self.transcripts(items + [item])) else { return }
    finish(.scanned(card))
  }

  func dataScanner(
    _ dataScanner: DataScannerViewController,
    becameUnavailableWithError error: DataScannerViewController.ScanningUnavailable
  ) {
    finish(.failed("The scanner stopped being available."))
  }

  private func consider(_ allItems: [RecognizedItem]) {
    items = allItems
    guard !finished, let card = CardTextParser.parse(Self.transcripts(allItems)) else { return }
    if card.expiryMonth != nil {
      finish(.scanned(card))
      return
    }
    numberOnly = card
    guard grace == nil else { return }
    grace = Task { @MainActor [weak self] in
      try? await Task.sleep(nanoseconds: CardScanViewController.expiryGraceNanoseconds)
      guard !Task.isCancelled, let self, let card = self.numberOnly else { return }
      self.finish(.scanned(card))
    }
  }

  private func finish(_ outcome: CardScanOutcome) {
    guard !finished else { return }
    finished = true
    grace?.cancel()
    scanner.stopScanning()
    dismiss(animated: true) { [completion] in
      completion(outcome)
    }
  }

  private static func transcripts(_ items: [RecognizedItem]) -> [String] {
    items.compactMap { item in
      if case .text(let text) = item { return text.transcript }
      return nil
    }
  }
}
```

```swift
import AVFoundation
import ExpoModulesCore
import VisionKit

public class CardScannerModule: Module {
  private var pending: Promise?

  public func definition() -> ModuleDefinition {
    Name("CardScanner")

    // Both run on the main queue, so assumeIsolated holds; it also keeps each
    // closure's return type explicit instead of inferring a Task from it.
    AsyncFunction("isSupportedAsync") { () -> Bool in
      MainActor.assumeIsolated {
        if #available(iOS 16.0, *) {
          return DataScannerViewController.isSupported
        }
        return false
      }
    }.runOnQueue(.main)

    AsyncFunction("startScan") { (promise: Promise) in
      MainActor.assumeIsolated {
        self.startScan(promise)
      }
    }.runOnQueue(.main)
  }

  @MainActor
  private func startScan(_ promise: Promise) {
    guard pending == nil else {
      promise.reject("E_BUSY", "A card scan is already running.")
      return
    }
    guard #available(iOS 16.0, *) else {
      promise.reject("E_UNSUPPORTED", "The native card scanner needs iOS 16 or later.")
      return
    }
    guard DataScannerViewController.isSupported else {
      promise.reject("E_UNSUPPORTED", "This device cannot run the native card scanner.")
      return
    }
    pending = promise

    switch AVCaptureDevice.authorizationStatus(for: .video) {
    case .authorized:
      present()
    case .notDetermined:
      AVCaptureDevice.requestAccess(for: .video) { granted in
        Task { @MainActor in
          if granted {
            self.present()
          } else {
            self.reject("E_PERMISSION_DENIED", "Camera access was not granted.")
          }
        }
      }
    default:
      reject("E_PERMISSION_DENIED", "Camera access is denied or restricted.")
    }
  }

  @available(iOS 16.0, *)
  @MainActor
  private func present() {
    guard DataScannerViewController.isAvailable else {
      reject("E_UNAVAILABLE", "The card scanner is not available right now.")
      return
    }
    guard let presenter = topViewController() else {
      reject("E_UNAVAILABLE", "There is no screen to present the scanner from.")
      return
    }
    let scanner = CardScanViewController { [weak self] outcome in
      self?.finish(outcome)
    }
    let navigation = UINavigationController(rootViewController: scanner)
    navigation.modalPresentationStyle = .fullScreen
    presenter.present(navigation, animated: true)
  }

  // The refund confirm sheet is an RN Modal, i.e. already a presented
  // controller; presenting from beneath it would put the scanner behind it.
  @MainActor
  private func topViewController() -> UIViewController? {
    var top = appContext?.utilities?.currentViewController()
    while let next = top?.presentedViewController, !next.isBeingDismissed {
      top = next
    }
    return top
  }

  @MainActor
  private func finish(_ outcome: CardScanOutcome) {
    switch outcome {
    case .scanned(let card):
      guard let promise = pending else { return }
      pending = nil
      var result: [String: Any] = ["pan": card.pan, "environment": "device"]
      if let month = card.expiryMonth, let year = card.expiryYear {
        result["expiryMonth"] = month
        result["expiryYear"] = year
      }
      promise.resolve(result)
    case .cancelled:
      reject("E_CANCELLED", "The card scan was cancelled.")
    case .failed(let message):
      reject("E_SCAN_FAILED", message)
    }
  }

  @MainActor
  private func reject(_ code: String, _ message: String) {
    guard let promise = pending else { return }
    pending = nil
    promise.reject(code, message)
  }
}
```
